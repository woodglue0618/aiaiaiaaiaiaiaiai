## 1. 벤치와 계단: 확보 완료, 현장 확인 필요

- 원본: `../../dist/map-data.json`의 OpenStreetMap 스냅샷. 스냅샷 시각은 `2026-10-28T05:19:18Z`다. 이는 DB 추출 시각이며 개별 시설의 최근 확인일이 아니다.
- 원본 수집 범위: 도로·계단은 남서 `(37.580, 127.020)` ~ 북동 `(37.611, 127.058)`, 벤치는 남서 `(37.584, 127.025)` ~ 북동 `(37.607, 127.053)`.
- 벤치: `amenity=bench`.
- 계단: `highway=steps`. 이 중 `conveying=yes/forward/backward/reversible`이면 에스컬레이터로 먼저 분류한다. 현재 원본의 steps 155구간 중 1구간이 이에 해당한다.
- 에스컬레이터 OSM 예: https://www.openstreetmap.org/way/550974490 — 운행 방향과 가동 여부는 미확인.
- GeoJSON 좌표 순서는 `[경도, 위도]`, 좌표계는 WGS84다. CSV의 선형 대표 좌표는 꼭짓점의 단순 평균이며 출입구나 진입점이 아니다. 경로 연결에는 원래 LineString과 OSM 노드 ID를 사용해야 한다.
- 지도에 등록됐다는 의미이며 현장 실재·철거·착석 가능·사유지 진입·휠체어 접근성을 검증한 것은 아니다. 누락 시설도 있을 수 있다.
- 라이선스: © OpenStreetMap contributors, ODbL 1.0. OSM 추출 DB의 재배포에는 표시 및 ODbL 조건을 적용한다. 공식 설치자료는 별도 파일로 유지했다.
- 태그 정의: https://wiki.openstreetmap.org/wiki/Tag:amenity=bench / https://wiki.openstreetmap.org/wiki/Tag:highway=steps / https://wiki.openstreetmap.org/wiki/Key:conveying
- 이용조건: https://www.openstreetmap.org/copyright

## 서비스에 적용하는 순서

1. 벤치는 GeoJSON Point로 지도에 표시하고 현장 확인 상태를 함께 표시한다.
2. 계단은 점 장애물 대신 원래 LineString/OSM way ID로 보행 그래프의 해당 구간을 제외한다.
3. 벤치와 도로의 실제 진입 연결을 확인한 뒤 휴식 경유지로 사용한다. 직선으로 가깝다는 이유만으로 도달 가능하다고 처리하지 않는다.
4. 에스컬레이터는 위치·방향·층 연결을 확보한 뒤 방향성 있는 경로에 반영한다. 가동 여부는 별도 자료가 필요하다.
5. 데이터가 없으면 시설이 없거나 안전한 길이라고 추정하지 않고 미확인 상태를 유지한다.

## 재생성

프로젝트 루트에서 `python3 donghaeng-nav/scripts/extract-accessibility.py`를 실행하면 저장된 두 원본으로 CSV·GeoJSON·요약을 재생성한다. 네트워크 호출은 없다.

학교 주변 신규 OSM 추출에는 `school-overpass.ql`을 Overpass API에 제출할 수 있다. 기존 원본 갱신 또는 앱 반영은 이 정리 작업에서 수행하지 않았다.
